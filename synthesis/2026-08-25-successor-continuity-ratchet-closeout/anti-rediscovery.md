# Anti-rediscovery — Successor Continuity / Ratchet

## Do not reopen these as novel primitives

The following mechanisms were explicitly subtracted during the 2026-08-25 continuity exploration:

- long-term memory / transcript persistence;
- event sourcing and provenance;
- indexed retrieval / materialized views;
- selective invalidation / incremental recomputation / change pruning;
- truth-maintenance and belief revision;
- heterogeneous context composition / MCS;
- durable workflow checkpoint/replay and worker replacement;
- idempotency / in-doubt effect reconciliation;
- durable wait / callback / condition-triggered resume;
- case management with open cases and no current enabled task;
- social commitment lifecycle across Agent turnover;
- organizational routines / transactive memory;
- living evidence re-adjudication;
- generic typed policy composition;
- recursive state machines that retain enough state for later branching.

Their existence is positive solution-domain content. Use them as baselines or components rather than re-proving them inside Ordivon.

## Distinctions worth preserving

```text
Retention != Succession != Ratchet
History != CurrentAuthority
Resume != Re-admission
NoActionNow != Complete
UNKNOWN != Failure/Success
Effect recovery is effect-owner-relative
TemporalRole != PresentClaimSupport != Authority
InformationNecessary != FiniteAgentConsumable
DeletionEssential != JointIrreducible
Complementarity != Emergence
```

## Current residual

`responsibility-preserving reactivation` remains useful:

```text
recover named obligation / work identity
→ recover qualified history
→ resolve current owners
→ reconcile ambiguous effects owner-relatively
→ re-observe load-bearing current Reality
→ recompile current action / non-action
```

This is an engineering discipline, not a presently established new joint capability.

## Reopen only when

```text
NaturalPressure
AND MatureBaselineResidual
AND IdentifiableDeletion
AND IndependentConsequence
```

If a fair mature generic composition reproduces the qualified outcome, classify the result as operational composition / scoped complementarity and stop escalation.
