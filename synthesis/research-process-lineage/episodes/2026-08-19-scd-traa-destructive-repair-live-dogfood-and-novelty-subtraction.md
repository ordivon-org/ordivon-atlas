## Question

The route began from a practical Agent question:

> When can a compressed / projected Working View safely stand in for a richer authoritative computational description during a transformation?

The initial temptation was to treat this as generic task-relevant information preservation.

## Initial position

Early formulations assumed one or more of:

- a primitive transformation-information map;
- a universal concrete state domain;
- equivalence classes as the general adequacy structure;
- semantic soundness as sufficient adequacy;
- a generic set of admissible contexts;
- fact/truth-role labeling as enough to prevent Agent misuse.

Each of these made the problem look simpler than the actual semantics.

## Destructive sequence

### 1. Circular relevance was removed

`Phi_T = all information needed for T` was rejected as a primitive because it renamed the adequacy question. Independent transformation contracts / typed obligations became the source of required judgements.

### 2. Universal carrier assumptions were removed

State-only semantics failed on trajectory properties; trace-only repair failed on hyperproperties, concurrency and open interaction. The semantic carrier became owner/model-native rather than SCD-mandated.

### 3. Equivalence-only adequacy was weakened

Refinement, simulation and conservative approximation showed that semantic loss can be directional. Equality/equivalence survived only as a special case.

### 4. Soundness was separated from sufficiency

A conservative `UNKNOWN` view can be semantically sound yet fail to discharge a transformation obligation. Adequacy therefore became obligation-indexed rather than a unary property of a view.

### 5. Context closure was scoped

Local refinement need not survive composition. Universal contextual closure was too strong, while an untyped `AdmissibleContext` mixed semantic scope, authority, current existence, capability, permission and selection. Preservation scope became contract-relative and typed.

### 6. Harness dogfood separated exactness from semantics

Using the real `WorkingSet -> WorkingView` boundary, fixtures established:

- exact view identity can coexist with semantic insufficiency;
- sound views can remain unresolved for a target judgement;
- exact provenance can carry a wrong-way semantic summary;
- locally equivalent descriptions can be separated by a retry-sensitive context.

This preserved a clean owner boundary: Harness owns exact cognition/projection facts; SCD owns semantic adequacy of that projection for a judgement.

### 7. Current-corpus prediction was separated from semantic law

The current Tool catalog made `stable-key` appear to predict keyed idempotency perfectly. A schema-valid `natural + stable-key` counterexample showed that the apparent converse was a finite-corpus correlation, not a constitutive law.

This prevented empirical classifier performance from being promoted into semantic standing.

### 8. Live Agent dogfood exposed model-prior bridge completion

DeepSeek and GLM behaved differently across semantic morphologies. Some premise bundles caused a model to silently complete an unstated bridge to a higher-order standing; others did not. Truth-role labels and generic anti-bridge instructions were not universal controls.

This falsified a universal `CrossTruthRolePromotion` story and moved model-specific failure into Harness/Agent cognition research.

### 9. The surviving semantic mechanism contracted toward support topology

Repeated representation ablations showed that no single magic label was required. Explicit non-establishment, a closed target-scoped standing-sufficient support graph with no path to target, and an undischarged target proof obligation could all represent the relevant semantic boundary in tested cases.

The stronger surviving idea became:

> semantic substitution may need to preserve owner-qualified inferential standing topology / support closure for the target obligation, not merely positive facts or entities.

Open-world caution remains essential: `edge absent from view` is not automatically `edge known unestablished` unless target-scoped closure standing justifies that conclusion.

### 10. Novelty was aggressively subtracted

Generic warrants, evidence-force calibration, argument/support graphs, proof obligations, provenance-aware semantic roles, proof-carrying actions and graph contracts were recognized as existing theory families rather than TRAA inventions.

The residual novelty claim therefore narrowed substantially instead of expanding.

## Current result

Current candidate identity:

`transformation-relative, directional, obligation-indexed, scope-qualified semantic substitutability`.

Current strongest empirical/theoretical residual:

- positive semantic content alone may be insufficient when an Agent-visible abstraction is used as a semantic substitute across heterogeneous owner truth boundaries;
- target-scoped inferential standing topology, including known non-established bridges or undischarged obligations, may be part of the information that must survive projection;
- model-specific cognitive reliability remains separate from semantic substitutability.

No new SCDF, Foundation, production schema or universal bridge engine was admitted.

## Surviving methodological lesson

This episode is valuable partly because the theory became **thinner through falsification**. Repeatedly, a universal ontology or convenient representation was rejected in favor of owner-native semantics plus narrower typed obligations.

`Research progress != concept accumulation`.
