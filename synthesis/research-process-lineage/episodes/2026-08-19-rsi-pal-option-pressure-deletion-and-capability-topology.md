## Known theory != demonstrated capability

This became the decisive repair.

Existing theory can explain a responsibility without showing that current Agents perform it reliably. Computing evidence makes the gap concrete:

- F8A: more explicit candidate variation is not reliably better;
- F11: generic option-aware reasoning does not reliably identify latent option value;
- P9: more evidence/search is not monotonically better;
- C6: more/full context does not reliably form the correct next pressure.

F17 therefore remains useful not because its certificate shape is novel, but because it prospectively tests an unresolved capability against later owner-admitted decision change rather than hidden labels or self-score.

## Surviving methodological lesson

This episode demonstrates a stronger form of negative research discipline:

```text
open a promising theory frontier
-> make its hidden distinctions explicit
-> build hostile fixtures
-> subtract mature prior art mechanism by mechanism
-> delete the theory when no irreducible fixture remains
-> return to owner-native evidence
-> distinguish theory maturity from capability maturity
-> inspect identifiability before admitting the next experiment
-> accept unused research capacity when Reality supplies no clean test
```

The result is not failure to find novelty. It is an anti-rediscovery asset and a more truthful map of where Ordivon is actually strong, weak, partial, or currently untestable.
