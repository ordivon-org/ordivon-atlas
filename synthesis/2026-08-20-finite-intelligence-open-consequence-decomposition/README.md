2. Relevance itself was opened: dynamic preferences, objective-basis change, effect/affordance discovery and future ways of mattering were separated.
3. Future consequences/problems were split into revelation, activation and generation. New capabilities, institutions, metrics and deployed representations can causally create new consequential regimes.
4. Capability growth can increase absolute knowledge while increasing relative epistemic/governance debt because generative reach can outgrow recognition, discrimination and repair along different scales/latencies/localities.
5. Standing was shown non-compositional by default: component standing requires an explicit composition warrant, sufficient interfaces and valid context assumptions.
6. Interface sufficiency became an identification problem. Finite tests can falsify scoped sufficiency but cannot certify unrestricted open-world completeness.
7. Repeated interface repair opened Decomposition Adequacy: MissingInterface != WrongDecomposition != IntrinsicNondecomposability.
8. Multiple useful decompositions generally cannot be compressed into one cheap master partition: common refinement can explode while common coarsening deletes complementarity.

10. A coding argument gives a bounded pair-exposure result over already-declared loci, while preserving the warning that boundary exposure is not interaction discovery.
11. The primitive-locus assumption was then opened: candidate loci may be relations, trajectories, events, collective modes or fields; `LocusDiscovery != LocusTyping`.
