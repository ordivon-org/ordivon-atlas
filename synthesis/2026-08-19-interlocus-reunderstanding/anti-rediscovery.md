Prevent future Human/Agent work from repeating settled repairs, confusing explanatory layers with owner authority, or promoting reference engineering artifacts by inertia.

## Core-law recovery guard

Do not recover C1–C7 as an a priori list. Preserve the research transition:

1. six-law candidate;
2. hostile source-grounding fixture -> C3 too weak;
3. conflicting current evidence + last-write-wins counterexample -> genuine missing C7;
4. C6 `Acyclic Warrant` weakened/repaired to `Well-Founded Warrant` to allow grounded recursion;
5. bounded historical coverage found no current C8 pressure.

This is anti-rediscovery value because a future researcher may otherwise reopen source grounding, conflict preservation or recursive-warrant questions as if untested.

## Engineering recovery guard

Before adding a new Interlocus engineering primitive, ask:

1. Is this only a source-fenced explanation of a current TargetUse? If yes, Capability Path Explanation v0 probably already covers it.
2. Is this a hypothetical intervention/sufficiency claim? If yes, use Counterfactual Repair Explanation v0 and keep effects hypothetical/model-relative.
3. Is the issue selection, permission, utility/risk or live execution authority? Then it belongs to Harness/consumer, Normative, objective owners or execution owners rather than new Interlocus truth.
4. Does the proposal reduce authoritative source reads, or only make cross-source joining safer? The demonstrated value is the latter.
5. Is there repeated real consumer pressure/prospective value evidence? If not, keep the result at review/reference level.

## Semantic reopen triggers

Reopen owner theory only if at least one occurs:

- a genuine capability regime cannot be represented without semantic loss by current NDF0–NDF5/NCT responsibilities;
- a serious hostile case satisfies the current C1–C7 interpretation yet still yields an obvious Interlocus semantic failure;
- a new empirical regime falsifies the InterLocusCapability carrier or an existing composition/projection/currentness boundary;
- current owner-native publication advances beyond the source fences used by this synthesis and changes the relevant standing.

New applications, new names, more examples or implementation enthusiasm are not semantic reopen triggers.
