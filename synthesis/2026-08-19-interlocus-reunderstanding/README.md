1. the rename followed a deeper carrier repair already made by `Communicability -> InterLocusCapability`;
2. `locus` was deliberately reconstructed without creating a Locus Foundation or global node ontology;
3. an initial six-law explanatory basis was **falsified** by hostile evidence-conflict/source-grounding fixtures, producing a repaired C3 and a new C7;
4. engineering value was found mainly in source-fenced warrant explanation, not in refactoring Runtime/Workstation/Finance/Harness into a new Interlocus layer;
5. Capability Path Explanation and Counterfactual Repair Explanation were separated because diagnosis, sufficiency, minimal repair, permission, selection, execution and restored standing are distinct proof roles;
6. consumer-value dogfood narrowed the benefit to **decision compression / machine-enforceable cross-proof-role guardrails**, not fewer authoritative source reads;
7. the attempted Interlocus×Harness×Normative action-admission bridge produced a deletion result: **no third generic Interlocus contract** and no Interlocus-owned selector/action authority.

These are precisely the parts most likely to be rediscovered if only current end-state theory is retained.
