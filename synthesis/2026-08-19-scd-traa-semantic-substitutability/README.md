## What survived destructive repair

The route began with a loose question: whether an Agent-visible abstraction retains the information needed for a transformation. The current surviving candidate is substantially narrower:

> Under a semantic qualification, transformation contract, required judgement family and preservation scope, when may an abstraction substitute for a richer authoritative computational description without changing semantics in an inadmissible direction or licensing unsupported higher-order judgements?

Current shorthand:

`transformation-relative, directional, obligation-indexed, scope-qualified semantic substitutability`.

The working decomposition distinguishes:

1. directional semantic soundness;
2. obligation sufficiency;
3. scoped contextual preservation;
4. context-induced obligation coverage;
5. support/dependency standing for higher-order judgements.

This remains a derived programme across existing `SCDF2/3/4/5/7/9/10`. It does **not** establish `SCDF11`, a Foundation gap, a new global registry, or a production semantic-adequacy service.

## High-value empirical results

### Harness boundary

Real Harness `WorkingSet -> WorkingView` dogfood established in scope:

- `ExactProjection != SemanticSufficiency`
- `SemanticSoundness != ObligationSufficiency`
- `ExactProvenance != DirectionalSemanticSoundness`
- `LocalAdequacy != ContextualAdequacy`

Current Tool semantics also provide a real context separator: `mutate_workspace` and `patch_workspace` share a generic source-change projection but differ in retry-sensitive idempotency/correlation semantics. Generic functional similarity therefore does not imply recovery-sensitive substitutability.

### Support topology / bridge standing

The stronger surviving mechanism is not a magic `BridgeStanding` label. Current evidence points to **target-scoped inferential standing topology / support closure**:

- premises or support-looking facts do not automatically establish a higher target judgement;
- absence of an edge in an open/partial view is not equivalent to known non-establishment;
- a target-scoped closed support scope with no standing-sufficient path can justify local non-establishment;
- undischarged proof/support obligations can play an equivalent role in tested representations.

This sharpens `Resolved(v,q)`: semantic resolution is not "a model can guess q from v"; it requires standing semantic structure sufficient to decide the obligation.

### Model-specific bridge completion

Live DeepSeek/GLM dogfood showed that models can differ by semantic morphology. Some premise bundles trigger illicit completion of an unstated bridge; other boundaries are respected. Therefore:

`SemanticSubstitutability != ModelCognitiveReliability`

and:

`CurrentModelAccuracy != RepresentationValidityOracle`.

Model-specific attractor behavior belongs to Harness/Agent cognition research, not SCD owner truth.
