# Anti-Rediscovery Guard — Result / Achievement / Value / Materialization

Before opening another Ordivon-wide research branch about “what counts as a result”, “whether Ordivon has real achievements”, “why research did not become engineering”, or “whether Host/Atlas should store more result state”, recover this collection first.

## Already established

```text
Task != Result
Completed != Achievement
Output != Outcome
Outcome != Standing
Standing != Achievement
Achievement != Value
Value != Consumption
Consumption != RealizedBenefit
MetricGain != Improvement
Improvement != Optimality
Optimality != SystemImprovement
```

Achievement has at least two deletion-essential forms under current evidence:

- ObjectiveAchievement;
- DiscoveryAchievement.

Improvement is comparison-scope-relative. Optimality requires a justified feasible/search envelope. There is no universal open-world optimum or global Ordivon achievement/value scalar.

## Do not force research into engineering

Current materialization roles are:

```text
R1 ConsequenceRepair
R2 EpistemicApparatus
R3 ControlBoundary
R4 PersistenceRecovery
```

`Product/Direction` is a decision disposition, not R5.

`MaterializeToLearn != DeployConclusion`.

Semantic/default-judgement change, experiment formation, product/direction choice, option/reopen retention, explicit NO_OP, and no demonstrated consumption are all legitimate downstream dispositions.

## Do not infer consumption or benefit

A reference, implementation, similar practice, or source-preservation event is not sufficient by itself to establish causal consumption.

Realized benefit requires an observed beneficial consequence and adequate attribution standing for a named beneficiary/use scope.

## When new research is justified

New work is justified when a concrete counterexample breaks one of the current distinctions or admission conditions, for example:

- a fifth materialization role is deletion-essential;
- the achievement forms fail to classify a real consequential delta;
- a comparison claim cannot be represented without a stronger notion than scoped partial-order improvement/feasible-set optimality;
- current B6/B7 reconstruction causes a reproduced wrong decision or unacceptable recurring cost;
- new external evidence changes the dated empirical value profile.

Absent such a breaker, use this synthesis as the prior result rather than restarting the semantics from Task/activity volume.
