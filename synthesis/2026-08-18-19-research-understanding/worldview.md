## The anti-collapse set

The strongest recurring lesson across the portfolio is that several convenient approximations must not be silently promoted into equivalence:

- `Reality != Representation`
- `Evidence != Conclusion`
- `Occurrence != Cause`
- `Score != Measurement`
- `Structure != Meaning`
- `Attempt != Possibility`
- `Task != Run != Attempt`
- `Intent != Effect != DomainResult`
- `HistoricalValidity != Currentness`
- `Recovery != Re-admission`
- `Projection != Authority`
- `Importance != Foundation != Owner != Service`

Many individual lines already have durable upstream support. The new value here is the cross-owner compression: Ordivon repeatedly improves by finding **false semantic collapses** and retaining only distinctions that change correct judgment or action.

## Three broad worlds

### 1. Reality / domain world

World provides generic reality semantics while domain owners retain irreducible domain truth conditions. An object/event may legitimately have several owner-relative projections without those projections becoming duplicate mutable truth.

### 2. Computational / Agent world

- SCD protects Meaning.
- Computational Possibility protects regime-relative Possibility.
- Runtime protects concrete Realization evidence.
- Harness protects bounded cognition/run structure.
- Host protects durable Work continuity.

The key compression is:

`Description != Possibility != Realization`

and

`Task != Run != Attempt != Effect != DomainResult`.

### 3. Epistemic / research world

- Computer synthesizes across owners and revises methods/world-model hypotheses.
- Atlas provides discovery/history/recovery projection.
- Lab assists research production.
- Owner-native authority determines current semantic truth.

The key compression is:

`History != Currentness`, `Map != Authority`, and `Recovery Never Mints Authority`.

## Agent-first placement

Agent-first is best treated as a **stress/falsification regime**, not a universal ontology. Replacement, bounded context, Tool drift, external effects, recovery, multi-Agent composition and long-lived work expose hidden assumptions in older theories.

Correct pattern:

`Agent-era pressure -> owner-native test -> owner-native result -> Computer synthesis -> new owner questions`.

## Thin-structure law

The portfolio also supports a complementary rule: semantic decompression must not become structure inflation.

If a distinction does not change correct action, ownership, recovery, truth, or consequence, prefer reduction/localization/deletion.

A compact expression is:

> Maximize truth-relevant distinction while minimizing permanent structure.

This is a synthesis heuristic, not a new Foundation.
