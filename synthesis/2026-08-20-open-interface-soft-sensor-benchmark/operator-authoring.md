# WP-G Operator-Authoring Boundary

The authoring surface exists to let evidence produce a new admitted measurement operator without making every possible asymmetric action pre-admissible.

## Pre-event state

The agent may know that an operator-authoring mechanism exists, but cannot invoke arbitrary printer paths or raw auxiliary ports as scientific measurement actions. `G0` remains mirror preserving.

## Candidate artifact

A submitted `g*` artifact must declare:

- source text / generated geometry recipe;
- required physical parts and ports;
- fabrication preconditions;
- contact/pad binding;
- calibration procedure;
- readout contract and output semantics;
- expected operating range;
- validation procedure;
- rollback/removal procedure;
- provenance references to the evidence motivating the patch.

## Validation gates

1. schema completeness;
2. dependency closure within allowed physical authority;
3. static safety/boundary checks;
4. source and geometry digest freeze;
5. neutral-state fabrication sanity check;
6. owner-hidden blinded physical validation on independent replicas;
7. nuisance randomization/grounding;
8. only then registry admission.

Validation failure does not silently mutate the artifact; revisions receive new identity/digest.

## Persistence receipt

A registry claim requires later context reset on a fresh mirror-equivalent body and matched replicas with and without the registry entry. A shifted temporal/torsional family then tests whether the system revalidates, revises or downgrades rather than blindly reusing `g*`.

`PersistentReuse != BlindReuse`.
