# WP-I — Frozen Existing-Closure Ledger `C0`

Purpose: prove interface formation/recomposition, not grammar escape.

## Frozen deployed interface `I0`

Installed sensing is mirror-even. The agent receives only symmetric aggregate output from the old sensing branch, e.g. total/bridge resistance, paired-average strain and global load/energy. Labeled left/right old branch outputs are owner-only calibration channels and are never agent-visible.

## Physical parts `P0`

- symmetric deformable cartridge;
- fixed old sensing branch and landing pads;
- symmetrically located generic auxiliary landing-pad pair(s), physically present but inactive in `I0`;
- fixed automatic resistance readout/switching capable of reading an admitted auxiliary path;
- DIW printer/material already available before the episode;
- neutral-state registration geometry.

## Frozen construction grammar for WP-I

`G0-I` contains a pre-existing, source-fenced template family that can print a conductive sensing path between allowed auxiliary pads with an offset/unilateral geometry parameter. It also contains the generic auxiliary resistance-readout binding and calibration operation.

A valid `q*` is therefore demonstrably reachable before the episode:

`q* in C0 = Cl_(G0-I)(P0)`

while absent from deployed interface:

`q* notin I0`.

## Membership receipt

Before any agent-visible challenge, freeze:

- exact template source/hash;
- allowed geometry parameter bounds;
- permitted auxiliary pad identities in an opaque internal coordinate system;
- printer/material dependency versions;
- auxiliary readout/calibration contract;
- static validation rules;
- proof-by-construction or owner execution that at least one asymmetric member of the template family can be instantiated in a neutral calibration fixture.

The challenge must not preselect the successful `q*`; the family may include multiple offset/morphology choices. The agent must use evidence to choose/materialize a member.

## Invalid WP-I evidence

- merely unmasking owner-only left/right channels;
- changing only software aggregation when the raw discriminating channels were already agent-admissible;
- using a template/operator not frozen in `G0-I`;
- claiming grammar escape from a `q*` already in `C0`.
