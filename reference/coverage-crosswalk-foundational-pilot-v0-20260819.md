## Reference-model pressure

- **gap:philosophy-major-region** — Two independent current owners map directly and deeply to norm:philosophy, but Philosophy has no semantically appropriate CanonicalMajorRegion; counting it under Mind/Cognition/Language would be a navigation false positive.
- **gap:networking-distributed-systems** — Mature Network semantics lack a clean normalized external coordinate; adjacent computation/information/systems/engineering identities are insufficient.
- **gap:runtime-programming-systems** — Mature Runtime semantics lack clean Operating/Runtime/Programming Systems external coordinates.
- **gap:coordination-workflow-systems** — Host continuity/coordination architecture has only weak adjacent external coordinates; external-source search is required before classifying this as reference-model omission versus Ordivon-novel structure.
- **gap:normative-philosophy-granularity** — norm:philosophy is too coarse to distinguish ethics/normative theory/constitutive normativity from metaphysics/epistemology/mind; deeper Philosophy normalization is required.

## Critical controls

- Region member coverage does **not** transfer to the region.
- Adjacency is not coverage.
- Excluded current owners are not untouched spaces.
- Reference-model gaps are not Ordivon coverage gaps.
- `ORDIVON_NOVEL_STRUCTURE` remains distinct from `EXTERNAL_MAPPING_WEAK`.
